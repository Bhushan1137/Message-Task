# Frontend - Multi-Tenant Messaging Platform

This directory contains the **Next.js 16 (App Router)** client application for the Multi-Tenant Messaging Platform monorepo.

> [!NOTE]
> This frontend is part of the unified single monorepo. For full project setup, architecture, backend API documentation, database migrations, and instructions on running the entire application, please refer to the **[Root README.md](../README.md)**.

## Quick Start (Frontend Only)

```bash
# Run from the project root:
npm run dev:frontend

# Or run directly from this directory:
npm run dev
```

The application will be accessible at [http://localhost:3000](http://localhost:3000).
Ensure the Express backend is running on `http://localhost:4000`.
